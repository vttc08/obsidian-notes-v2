# Free DDNS/Domain Certificates
## ACME.sh
Installation
```bash
curl https://get.acme.sh | sh -s email=my@example.com
```
[acmesh-official/acme.sh: A pure Unix shell script ACME client for SSL / TLS certificate automation](https://github.com/acmesh-official/acme.sh)
- the script automatically installs the crontab to auto renew certificate
Add the alias if not added
```bash
alias acme.sh="~/.acme.sh/acme.sh"
```
